KMA Launcher v0.6.0

배포용 UI 정리, 첫 실행 안내, 설정 톱니바퀴 메뉴, 웹 로그인, Modrinth 모드 설치 버그 수정 버전입니다.

첫 실행 화면앱 아이콘과 `마인크래프트 런처 크마` 문구가 올라오고, 다음 화면에서 모드 설치 흐름을 보여줍니다.
설정 메뉴설정 클릭 시 톱니바퀴가 회전하고, 바로 아래에 메뉴가 펼쳐집니다.
모드 적용Modrinth에서 설치하면 모드 적용 영역에 바로 보이고, 실행 시 해당 인스턴스의 mods 폴더가 적용됩니다.
배포GitHub tag v0.6.0을 push하면 Release에 NSIS exe가 자동 업로드됩니다.
