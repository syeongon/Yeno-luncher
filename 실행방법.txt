YEON Launcher v0.4.2

이 버전은 v0.4.1에서 발생한 Rust 빌드 오류를 수정한 버전입니다.

[빌드 방법]
1. 압축을 풉니다.
2. 압축 푼 안의 파일들을 GitHub 저장소 최상단에 업로드합니다.
3. Actions로 이동합니다.
4. Build YEON Launcher Windows를 실행합니다.
5. 성공하면 YEON-Launcher-Windows-v0.4.2 Artifact를 다운로드합니다.

[수정된 오류]
cannot borrow `launcher` as mutable

원인:
minecraft-java-rs-core 0.4.1의 start()가 mutable launcher를 요구했습니다.

수정:
let launcher = Launcher::new(options);
↓
let mut launcher = Launcher::new(options);
